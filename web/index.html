Coding availability

Drag a column up or down (or scroll over it) to set how available you are that day. The shaded fill is availability; the solid bar is what you've actually used against that day's share. Double-click resets a day.

availability used vs that day's share over that day's share

Run /usage and type each percentage it reports. Each one is independent — set any, all, or none, whenever they drift. Enter 0 to go back to inferring that one.

Percentages are shares of your weekly subscription allowance, derived from local Claude Code transcripts — not API billing, which you don't pay. The absolute limit is an estimate until you calibrate it above or actually hit a limit; the split between days is accurate either way.
